# ToDoPrioritizer

A to-do app with an Eisenhower Matrix view. It runs entirely in the browser and
stores data on your device.

- Requirements: [docs/REQUIREMENTS.md](docs/REQUIREMENTS.md)
- Architecture and milestones: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)

## Setup

You need Node 26 LTS or later (see `.nvmrc`).

```sh
npm install
npm run e2e:install   # one-time download of the Playwright browsers
```

## Scripts

| Command                           | What it does                                   |
| --------------------------------- | ---------------------------------------------- |
| `npm run dev`                     | Starts the dev server at http://localhost:5173 |
| `npm run build`                   | Type-checks, then builds into `dist/`          |
| `npm run preview`                 | Serves the production build                    |
| `npm test`                        | Runs the unit and component tests (Vitest)     |
| `npm run test:watch`              | Runs Vitest in watch mode                      |
| `npm run test:coverage`           | Runs Vitest with a coverage report             |
| `npm run e2e`                     | Runs the end-to-end tests (Playwright)         |
| `npm run lint`                    | Runs ESLint                                    |
| `npm run typecheck`               | Runs the TypeScript compiler without emitting  |
| `npm run format` / `format:check` | Runs Prettier                                  |

`src/routeTree.gen.ts` is generated by the TanStack Router Vite plugin from the
files in `src/routes/`. Don't edit it by hand.
