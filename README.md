# ToDoPrioritizer

A to-do app with an Eisenhower Matrix view. It runs entirely in the browser and
stores data on your device. There are no accounts and no server.

- Requirements: [docs/REQUIREMENTS.md](docs/REQUIREMENTS.md)
- Architecture and milestones: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)
- Why things are the way they are: [docs/adr/](docs/adr/README.md) (Architecture Decision Records)

## Features

- **List view (`/`):**
  - Add, edit, and delete todos. Deleting asks for confirmation first.
  - Mark a todo done or not done. Done todos are kept, with the date they were
    completed.
  - Filter by Active, Completed, or All. The filter is kept in the URL, for
    example `/?status=completed`.
- **Matrix view (`/matrix`):**
  - Four quadrants: Do Now, Schedule, Delegate, and Delete. There is also an
    Unsorted tray.
  - Move todos by dragging them with a mouse or touch, or with the keyboard
    (pick up with Space, move with the arrow keys, drop with Space).
  - Or move them with each card's "Move" button.
  - Completed todos can be shown with the toggle, or with `?completed=true`.
- **Storage:** todos are saved in IndexedDB and are still there after a reload.
  Data stays in this browser on this device.
- **Accessibility:** the app is checked against WCAG 2.x AA with axe, in light
  and dark mode, on desktop and phone screens. Every action works from the
  keyboard, and screen readers announce changes.

## Setup

You need Node 26 LTS or later (see `.nvmrc`).

```sh
npm install
npm run e2e:install   # one-time download of the Playwright browsers
npm run dev           # http://localhost:5173
```

## Project layout

```
src/
  domain/   pure business rules and selectors (no React, no storage)
  data/     TodoRepository interface, plus Dexie (IndexedDB) and in-memory versions
  state/    TodoStore, TodoService, and the React hooks (useTodos, useTodoActions)
  routes/   TanStack Router file routes ("/", "/matrix")
  ui/       React components for the List and Matrix views
e2e/        Playwright tests: acceptance criteria, flows, accessibility, and performance
```

ESLint enforces the layers. For example, UI code can't import `src/data`.

## Notes

- `src/routeTree.gen.ts` is generated by the TanStack Router Vite plugin from
  the files in `src/routes/`. Don't edit it by hand.
- Playwright runs Chromium and WebKit. Firefox is disabled on this machine
  until the Microsoft Visual C++ Redistributable is installed:
  `winget install Microsoft.VCRedist.2015+.x64`. Then uncomment the Firefox
  project in `playwright.config.ts`.
- Performance timings vary a lot on laptops (CPU throttling). The perf config
  retries a failing measurement, and a pass on retry is reported as "flaky".
- While the app is in development, the stored data format may change without
  migrations (see `docs/ARCHITECTURE.md` §4.2).
